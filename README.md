# Gardening Association site template

A free website template for gardening clubs, allotment societies and small associations.

The live demo is the Ruddington Gardeners’ Association site: <https://teddsy.github.io/Gardening-association/>

The blank template, with example text you can replace, is at <https://teddsy.github.io/Gardening-association/template/>

The files in the root of this repository are the live demo. Start from the `template` folder when you make a site for your own club.

## Quick start

1. Download this repository as a ZIP (the green **Code** button, then **Download ZIP**), or **Fork** it on GitHub.
2. Open the `template` folder.
3. Follow [template/CUSTOMISE.md](template/CUSTOMISE.md) to change the club name, colours, words, seed list and pictures.
4. Publish that folder for free. The guide explains Netlify drag-and-drop and GitHub Pages.
