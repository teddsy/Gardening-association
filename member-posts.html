Supabase setup (for going live)

This demo keeps its data behind a small DataAdapter object. To go live, create a Supabase project, run supabase-setup.sql (tables profiles, posts, comments, RLS policies and a post-photos storage bucket), fill in the config block in this file's script and swap LocalAdapter for SupabaseAdapter. Only the public anon key belongs in the page – never the service-role key.
